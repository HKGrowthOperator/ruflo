# Assets

Source files for every motion piece. **Never describe the logo from memory — always reference the real file here.**

## Structure

```
assets/
├── logo/        # transparent HK logo — PNG (transparent) + SVG (vector master)
└── brandkit/    # colors (hex), fonts, spacing/lock-up rules, brand guidelines
```

## Needed (please add)

### logo/
- [ ] Transparent **PNG** (high-res, transparent background)
- [ ] Vector **SVG** master (preferred for crisp scaling)
- [ ] Lock-up / clear-space rules if available

### brandkit/
- [ ] Color palette (primary + secondary hex values)
- [ ] Fonts (files or names + weights)
- [ ] Any existing brand guideline PDF
- [ ] Logo do's & don'ts reference

> Once these are in place, the pipeline (brief → scene board → prompts → guard → export) can run with accurate logo anchoring.
