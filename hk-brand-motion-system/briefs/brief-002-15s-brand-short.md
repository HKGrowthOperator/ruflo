# Brief 002 — 15s HK Brand Short

- **ID:** brief-002 · **Piece:** Brand Short (brand + value)
- **Status:** READY (working palette/vector) — official hex/vector swap later
- **Language:** DE · **Duration:** 15s · **Master format:** 16:9 1920×1080 30fps (→ 9:16, 1:1)
- **Audio:** muted-safe · inherits all global rules from project `CLAUDE.md`

## 1. Goal
Show the brand AND the value: HK builds the system from the roots up, the four service areas are
the branches, and the result is real growth. Premium, calm, confident.

## 2. Core message
**"Erst das Fundament, dann das Wachstum."** The four branches = the four service areas.

## 3. Scene structure (15s)
```
S1 0–3s    Roots: foundation, values, processes, stability.
S2 3–6s    Trunk: HK as operating core; H+K integrate, readable.
S3 6–9s    Branches fan out — four limbs (the four service areas).
S4 9–11.5s Four service areas emphasized in turn + one cool flow pulse (AI as tool).
S5 11.5–13.5s Crown blooms (organic, life, growth).
S6 13.5–15s Full lock-up holds (+ optional tagline «TAGLINE» — review via hk-brand-language).
```

## 4. The four branches (symbolic, NO generic icons)
1. Social Media / Brand / Content   2. Websites / Onepager / Conversion / booking
3. Automations / interfaces / CRM / workflows   4. AI integration / pipelines / decision-ready
→ Each branch brightens/leafs in turn; differentiate by position + subtle leaf accent, not by icons.

## 5. AI allowed / not
- Allowed: one cool flow pulse along roots→trunk→branches; AI as a quiet tool.
- Not: AI in/over the crown, robots, AI icons, cyberpunk, HUD, religious, fantasy. (See CLAUDE.md.)

## 6. Crown (separate from AI)
Organic leaves, warm natural light, life/growth/freedom. No flow lines, no tech in the crown.

## 7. Style & motion
Premium, warm-dark-olive, restrained. Sequential organic build (roots→crown). Near-still camera,
slow ease-in-out. Crown slightly slower/softer than the structural build. Upright final lock-up.
